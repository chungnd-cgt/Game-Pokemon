# Sprite Pokémon

Thả file PNG vào thư mục này, tên file trùng với id trong `src/data/monsters.js`:

- `charmander.png`: mặt trước, dùng cho Pokémon đối thủ, màn chọn khởi đầu và đội hình
- `charmander-back.png`: mặt sau, dùng cho Pokémon của mình khi đánh (không bắt buộc)

Thiếu file nào thì game dùng hình vẽ tạm cho con đó. Ảnh được tự co giãn cho vừa khung,
nên kích thước nào cũng được (sprite 96×96 hay 64×64 đều ổn).
Sau khi thêm hoặc xoá file, khởi động lại `npm run dev`.
